# Basic Authentication

Basic Authentication implementation example with Spring Security and Spring Sessions

## Technologies
- Java 17
- Maven
- Spring Boot
- Spring Security
- Spring Session
- MySQL

## Running the Application

1. Clone repository
```
git clone https://github.com/sevketbuyukdemir/basic-authentication.git
```
2. Run MySQL via Docker Desktop
- To create MySQL container for the first time.
```
docker-compose up -d
```
- To start the existing MySQL container
```
docker-compose start
```
- To stop the MySQL container
```
docker-compose stop
```
3. Run Spring Boot application
4. You can find Postman collection from resources.
