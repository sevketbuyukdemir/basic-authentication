# Basic Authentication

Basic Authentication implementation example with Spring Security and Spring Sessions

## Technologies
- Java 17
- Maven
- Spring Boot
- Spring Security
- Spring Session
- MySQL

## Running the Application

1. Run MySQL via Docker Desktop
- To create MySQL container for the first time.
```
docker-compose up -d
```
- To start the existing MySQL container
```
docker-compose start
```
- To stop the MySQL container
```
docker-compose stop
```
2. Run Spring Boot application
3. You can find Postman collection from resources.
